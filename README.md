# HW2 — 全台 22 縣市人口變化動態視覺化

課程：資料分析與視覺化應用｜作業二：D3.js Dynamic Visualization

## 主題與動機
延續 HW1 主題，改用完整的全台 22 縣市資料，比較人口實際增減人數與相對變動率；考量老師提出「小縣市分母較小」的意見，保留人口年增減率與每10萬人換算值，同時以實際增減人數作為預設主要指標，避免誤將百分比等同實際人口影響。

## 資料期間與來源
- 114年（2025）09月底《縣市村里鄰戶數及人口數》，「09」工作表，欄位「人口數／計」
- 115年（2026）09月底同一統計表，「09」工作表，欄位「人口數／計」
- 來源：內政部戶政司，使用者下載之官方 Excel 原始檔
- 排除「總計、臺灣省、福建省」三個彙總列，保留 22 縣市

## 計算方式
- 實際人口增減：2026年9月人口 - 2025年9月人口
- 年增減率 (%)：實際增減 / 2025年9月人口 × 100
- 每10萬人相當變動人數：實際增減 / 2025年9月人口 × 100,000

**特別注意：**「每10萬人」只是與年增減率同等資訊的等比例換算；它不是實際增減的人數，也不能完全消除小縣市的相對波動。

## 互動功能
1. 透過按鈕切換三種比較指標
2. 透過下拉選單切換升冪、降冪、縣市名稱排序
3. 篩選人口增加、人口減少或全體縣市
4. 移入長條顯示 Tooltip，包含兩期人口、增減人數、增減率與每10萬人數
5. `transition()` 動畫呈現座標軸、長條與數值變動

## X 軸與 Y 軸
```js
const x = d3.scaleLinear().domain([-extent, extent]).range([0, width]);
const y = d3.scaleBand().domain(visible.map(d => d.county)).range([0, h]).padding(.18);
yaxis.call(d3.axisLeft(y).tickSize(0));
```
Y軸顯示縣市，X軸顯示選定的人口變動指標；兩側使用同一量尺、以0為共同基準。

## 統計限制
此統計是戶籍人口存量，不可由這兩張表單獨拆解出生、死亡、遷入或遷出的人數。要分析原因須再加入出生死亡及遷徙統計資料。
