## HW2 - Dynamic Visualization using D3.js

### 主題
台灣縣市人口變化：動態比較

### 作業設計
本作業延續 HW1 的人口主題，將靜態長條圖改為動態互動視覺化。

老師在 HW1 建議中指出，不同縣市人口規模差異很大，因此本作業新增「每 10 萬人相當變動人數」作為共同分母：

`每 10 萬人相當變動人數 = 人口年增減率 × 1000`

例如 +0.25% = 每 10 萬人相當增加 250 人。

### 動態功能
- 切換「每 10 萬人相當變動」與「人口年增減率」
- 由高到低、由低到高、依縣市名稱排序
- 滑鼠移入長條顯示 Tooltip
- 切換時使用 D3 transition 動畫
- Y 軸以 `scaleBand()` 顯示縣市

### Y 軸程式
```javascript
const y = d3.scaleBand()
  .domain(data.map(d => d.county))
  .range([0, height])
  .padding(0.28);

yAxisG.call(d3.axisLeft(y).tickSize(0));
```
